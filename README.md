# Pj B. | Portfolio

This is the personal portfolio website of **Pj B.**. It is an interactive desktop that runs in the browser and shows my GitHub projects.

> This repository is for my portfolio only. It is not a template and is not meant to be copied or reused.

## What's inside

- A pixelated boot-up screen that opens into the desktop
- An **About me** window with a short introduction
- A **Files** window that lists my public GitHub repositories, loaded live from GitHub
- A **Terminal** window with commands for exploring my projects
- A parallax mountain wallpaper with a few color themes
- Loading screens when apps open, and a layout that also works on phones

## Built with

Plain HTML, CSS and JavaScript, hosted on GitHub Pages.
